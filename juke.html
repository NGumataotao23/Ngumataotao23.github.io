Object Oriented Jukebox
Final made for Object Oriented class. This uses the outdated Microsoft Foundation Class for its UI
components. While this Jukebox does not actually play music it does simulate the characteristics if
a jukebox. You must enter 25 "cents" to start a song and you can choose one of 8 different songs to play.
The program will then "play" a song for about 5 seconds, during that 5 seconds another song cannot be
played. You can view information about the song like its runtime, album, and release date while a song is playing.
