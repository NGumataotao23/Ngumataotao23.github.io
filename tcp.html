TCP ChatRoom
Uses TCP connectivity to host a simple chatting service between 2 Clients.
Each client spawns its own seperate thread to establish connection with the server file.
The server file then controls the sending of messages and the use of commands.
One of the main features of this chat room is the ability to file share between 2 users.
